# American-Gallery-Data-Analysis-Time-Series-Forecasting-in-Python
An end-to-end data analysis project on American Gallery dataset including data cleaning, exploratory analysis, and time series forecasting. Uses Python, Pandas, and visualization tools to uncover trends and generate insights from temporal data.

Project Overview

The objective of this project is to analyze historical data and uncover trends over time while preparing the data for forecasting.

This project demonstrates a **real-world data workflow**:
- Data Cleaning & Preprocessing  
- Exploratory Data Analysis (EDA)  
- Time Series Analysis  
- Trend Identification
  
## Dataset Description

The dataset contains historical records related to the American Gallery, including:

- Date / Time information  
- Numerical variables (sales, counts, etc.)  
- Categorical features  
- Other relevant attributes  

## 🧹 Data Preprocessing

Key preprocessing steps performed:

- Handling missing values  
- Converting date columns into datetime format  
- Sorting time-based data  
- Removing duplicates and inconsistencies  
- Feature preparation for analysis  

## Exploratory Data Analysis (EDA)

The dataset was explored using visual and statistical techniques:

- Distribution analysis  
- Trend visualization over time  
- Category-wise comparisons  
- Correlation insights
  
## Time Series Analysis

A key part of this project is analyzing how data changes over time:
- Time-based aggregation  
- Monthly / yearly trend analysis  
- Pattern identification  
- Preparation for forecasting
  
## Visualizations

The project includes multiple visualizations such as:

- Line charts for time trends  
- Bar charts for comparisons
